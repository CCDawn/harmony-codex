# 2026-10-12 手机链路修复

## 已确认原因
- 桥接 8787 正常，但桌面接口 127.0.0.1:9229 拒绝连接；普通会话500及个人助手502来自同一本机依赖。
- 当前官方桌面未带远程调试参数。未擅自重启或结束工作。
- 语音任务实际使用系统conhost隐藏启动PowerShell，旧校验拒绝该包装。
- 隧道长期运行时，64 KiB日志尾截断使早期成功事件丢失，误报未验证。

## 实现
- 语音任务严格支持合法系统conhost包装和安全直接PowerShell形式。
- 逐行读取当前连接尝试的日志证据，SSH退出后不复用旧成功事件。
- 统一状态与详细桌面诊断使用同一探测；过滤不存在进程的监听记录。
- 本机桌面接口缺失时，500/502展示恢复桌面连接提示。
- 状态文件原子替换兼容Windows PowerShell 5.1；保持PowerShell中文文件UTF-8 BOM。
